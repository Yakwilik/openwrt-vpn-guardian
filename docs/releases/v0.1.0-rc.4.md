Четвёртый предварительный релиз OpenWrt VPN Guardian для **OpenWrt 24.10.4 с opkg**. Устраняет задержки переключения VPN-ноды и ошибки отображения событий в панели управления.

## Исправления

- **Health check ChatGPT:** добавлена обязательная анонимная GET-проверка *https://chatgpt.com/backend-api/me* через VPN backend. Ожидается HTTP 401 (доступ к сервису есть, но нет авторизации); HTTP 403 и сетевые ошибки отклоняют ноду. Проверка дополняет OpenAI API, Google, Cloudflare и Telegram, но не гарантирует прохождение авторизованных запросов Codex через Cloudflare.
- **Быстрее failover:** watchdog за одну итерацию проверяет до трёх подходящих нод вместо одной. Если остались непроверенные кандидаты, продолжает подбор без дополнительных двух циклов подтверждения после каждой неудачной партии.
- **История событий:** подтверждённые переключения больше не вытесняются повторяющимися сообщениями о первом, ещё неподтверждённом сбое. Последовательные переключения на разные ноды не удаляются как дубликаты.
- **Время событий:** API определяет локальное смещение времени OpenWrt через системную команду date. Для настроенного MSK-3 отображается московское время, а не UTC.
- **Интерфейс:** обновление истории каждые 15 секунд вместо 60; счётчики автоматически учитывают пять health check.
- **Совместимость истории:** новые записи содержат число проверок, прежние 7-колоночные записи остаются читаемыми. Восстановление событий учитывает сохранённый результат проверки, а не только число успешных HTTP-ответов.

## Обновление

Пакеты выпускаются для *aarch64_cortex-a53 (mediatek/filogic)*, *arm_cortex-a7_neon-vfpv4 (ipq40xx/generic)* и *x86_64 (x86/64)*. Как и прежде, пакетная сборка включает v2rayA 2.5.8 и два варианта патченного dnsmasq-full 2.90-r5.1 для OpenWrt и GL.iNet.

При обновлении уже настроенного Guardian достаточно заменить пакет *vpn-guardian* **той же архитектуры**, сохранив */etc/vpn-guardian/*. Для вступления изменений watchdog, collector и API в силу их нужно перезапустить. Повторно выполнять *vpn-guardian init* или менять установленный dnsmasq-full не требуется.

Для новых установок см. [инструкцию](https://github.com/Yakwilik/openwrt-vpn-guardian/blob/v0.1.0-rc.4/docs/installation.md). Не устанавливайте оба варианта dnsmasq-full одновременно.

**Совместимость:** только OpenWrt 24.10 с opkg и соответствующими пакетными зависимостями; поддержка произвольных прошивок и маршрутизаторов не гарантируется. Сохраните копию конфигурации и текущего бинарника перед обновлением.

## Проверки

Пройдены Go-тесты, go vet, проверка типов и production-сборка React, Linux/arm64-сборка. Новый read-only probe проверен через реальный SOCKS VPN backend GL-MT3000 (5/5 успешных ответов на момент проверки). Публикация пакетов дополнительно требует успешных проверок CI для всех трёх архитектур и обеих версий dnsmasq.
