## Scope and limitations

The fault-injection tests use *tests/router/acceptance.sh* and the operator-only helper under *tests/router/corectl*. Recovery times are observations from these runs, not worst-case bounds.

Tests covered the configured IPv4 LAN. Physical Wi-Fi radio behavior, arbitrary IPv6 configurations, all 77 individual VPN nodes, clean IPK installation/upgrades/removal, and multi-day continuous stability were not validated here.

One earlier exploratory request to the public IP endpoint timed out; subsequent LAN checks using multiple endpoints passed. The cause of that individual timeout was not established. The Buf website returned HTTP 403 during an exploratory request; registry application-level access was not accepted as passing on that basis.

With VPN-only enabled, failure of the shared front can temporarily interrupt intercepted direct traffic too. The system must retain interception rather than silently send proxy-class traffic directly. Private/local management traffic remains excluded from interception.
