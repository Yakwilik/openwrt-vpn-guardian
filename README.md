# OpenWrt VPN Guardian

Выборочный VPN для OpenWrt: нужные домены и IP идут через VPN, остальной трафик — напрямую. Guardian следит за соединением, переключает недоступные ноды и показывает состояние в веб-панели.

## Установка

Для **OpenWrt 24.10 с opkg**. Доступны сборки для ARM64, ARMv7 и x86-64; [точные архитектуры и требования](docs/installation.md).

1. Откройте [Releases](https://github.com/Yakwilik/openwrt-vpn-guardian/releases) и скачайте два файла *.ipk* для архитектуры роутера: **vpn-guardian** и **v2raya**.
2. Скопируйте оба файла в */tmp* на роутере.
3. Подключитесь к роутеру по SSH и выполните:

~~~sh
opkg update
opkg install /tmp/v2raya_*.ipk /tmp/vpn-guardian_*.ipk
vpn-guardian init
~~~

Зависимости устанавливаются вместе с пакетами. Мастер настройки проверит их доступность, определит сеть и запросит:

- ссылки на подписки;
- разрешённые протоколы для отбора нод;
- логин и пароль v2rayA, если аккаунт ещё не создан.

При первой установке маршрутизация включится только после проверки конфигурации и VPN-соединения. В конце мастер покажет адрес веб-панели. Повторный *vpn-guardian init* позволяет изменить настройки отбора.

## После установки

Состояние, ноды и подписки доступны в веб-панели. По умолчанию включён **VPN-only**: при отказе VPN backend трафик выбранных сервисов блокируется, обычный direct-трафик продолжает работать.

DNS LAN-клиентов проходит через отдельный Guardian DNS dispatcher: локальные OpenWrt/DHCP-имена всегда остаются в dnsmasq, а для внешнего DNS можно выбрать system, custom или xray. Custom использует заданные числовые resolver-ы через VPN; Xray — отдельный DNS-only Xray с DNS-трафиком через активный VPN backend. По умолчанию Custom/Xray применяется только к доменам из VPN routing rules; этот режим можно отключить в панели и отправлять через него весь внешний DNS. DNS самого роутера остаётся системным, чтобы bootstrap VPN не зависел от уже работающего туннеля.

Домены и IP для VPN задаются в */etc/vpn-guardian/routing.json*. После изменения:

~~~sh
vpn-guardian validate
vpn-guardian apply
~~~
